# 65C02 coder — GP.ASM and 64tass

Two different jobs share this file, and they do **not** share a syntax:

- **`GP.ASM` blobs** — inline assembly inside `.BASL`/`.INC.BL` programs, assembled on the X16 at
  compile time by GPC's own line assembler. A small, strict subset. Most of this file.
- **The engine itself** — `source/**/*.asm`, assembled on the host by 64tass 1.60. Full assembler:
  `.section`/`.send`, `.proc`/`.pend`, `.byte`/`.word`, macros, `_local` labels.

Do not carry an idiom from one into the other. 64tass directives are a syntax error to GP.ASM.

## Git

When moving, renaming or deleting a tracked file use `git mv` / `git rm`, never plain `mv`/`rm` —
plain ones read as delete+add and lose the history.

# Part 1 — GP.ASM

## The block form

```basl
SORT.PASS:
    #REM 1
    GP.ASM
    REM CLD
    REM LDA {SORT.GAP%}
    REM STA {SORT.I%}
    GP.ENDASM
    #REM 0
    RETURN
```

- `GP.ASM` and `GP.ENDASM` are each **alone on their line**. The body rides in `REM` statements,
  **one instruction each**, because BASLOAD stores remark text byte for byte — outside a `REM`,
  `AND`, `ORA`, `EOR` and `ROR` tokenise into keywords and the text is destroyed.
- **Wrap the block in `#REM 1` … `#REM 0`.** BASLOAD's default (`#REM 0`) strips remark bodies, and
  the block then reaches the compiler *empty* and is refused as `block mismatch`. The trailing
  `#REM 0` restores BASLOAD's default, not the caller's.
- A comment inside the block is `REM ;text` — the `;` after the `REM`.
- **The assembler appends the `RTS`.** The blob is entered by `JSR`, so a `JSR` to a helper
  *inside the same blob* is stack-level and safe.

## What the assembler supports — and nothing else

**66 mnemonics**, 65C02 including `BRA`, `STZ`, `PHX/PLX/PHY/PLY`, `TRB`, `TSB`, `STP`, `WAI`,
`INC A`/`DEC A`, `BIT` immediate, and `(zp)` indirect. Generated from
`source/compiler/scripts/genasm.py` into `source/compiler/source/generated/gpasmtable.asm` — read
that script for the authoritative table.

**Deliberately absent: `BBR`, `BBS`, `RMB`, `SMB`.** Do not emit them.

**There are no directives and no data.** No `.byte`, no `.word`, no `.text`, no equates, no macros,
no conditional assembly. A constant table belongs in BASIC above the block, not inside it — and it
would have to be jumped over anyway.

**There are no expressions.** No `LBL+1`, no `<`/`>`, no arithmetic. If you need a computed address,
see the self-patching idiom below.

**Numbers**: `$` hex, decimal. Operands are written literally — `LDA ($2C),Y` names zero page by
address, not by symbol.

**A bare `A` operand means implied**: `ASL A` and `ASL` both assemble to one byte.

### Labels

- `LABEL: INSTRUCTION` on the same `REM` line, as in `REM SPGO: LDY {SORT.I%}`.
- **Six significant characters.** `ASM_NAME_LEN = 6`.
- **Labels do not cross `GP.ENDASM`.** Each block has its own table.

### Hard limits (`gpasmcode.asm`, at their architectural maximum)

| | |
|---|---|
| labels in one block | 32 |
| forward references awaiting resolution | 64 |
| fixups per program (blob calls + label refs + `{VAR}`) | 128 |
| `GP.ASM` blocks per program | 32 |
| total assembly per program (the pool) | 7,040 bytes |

These cannot be raised without widening an index — every subscript is `count*n` held in X. Hitting
one reports `OUT OF MEMORY`.

## `{VAR}` — reaching BASIC variables

`{NAME}` assembles to the variable's workspace address. All four rules below cost a build cycle each
to find; none of them announce themselves clearly.

1. **The program needs `#SYMFILE`, and it must come BEFORE the `#INCLUDE`s.** BASLOAD crunches names,
   so the name in the braces is not the name the code uses; `#SYMFILE` is the mapping. Placed after
   the includes, BASLOAD stops with `SYMFILE NOT ALLOWED IN <file>:<line>`. Missing entirely, GPC
   stops with `NO SYMBOL FILE FOR {} @ <line>` and then falls out to BASIC with a **`?STRING TOO
   LONG ERROR` that names neither the file nor the cause**.
2. **The variable must already have a slot** — its first assignment must be textually **above** the
   block. Otherwise: `UNKNOWN VARIABLE IN {} @ <line>`, again with a secondary `?STRING TOO LONG
   ERROR` that is fallout, not the cause. An init routine is the natural home; assigning the
   assembly's scratch variables to 0 up there is the house pattern.
3. **Dotted names work** (`{DOC.GOT.OFF}`) — and dotted is the house style, because it dodges
   BASLOAD's keyword trap. **Underscore does not.**
4. **The high byte is yours to keep zero.** Assembly that writes only the low byte of a `%` variable
   needs that variable initialised to 0 and never touched again from BASIC.

### Layouts

- **`%` integer**: two bytes. It holds a 16-bit address **verbatim above 32767** — 40960 stores as
  `$00,$A0` — so VERA and banked-RAM addresses pass through with no two's-complement trick.
- **String**: `{A$}` is the **slot**; the slot holds the block address; the length and text sit at
  fixed offsets in the block — the layout is in `docs/blitz/GP-BASIC.ASM.RESEARCH.md` §9. Read it
  rather than guessing.
- **Array**: pass `GP.ARRPTR(NAME$())` in a `%` variable. That points at element **zero**, with the
  3-byte header (count low, count high, type) *below* it. Type is `$40` string, `$00` numeric,
  bit 7 sub-array.

## Zero page, and what is actually free

**`zTemp0 $2C`, `zTemp1 $2E`, `zTemp2 $30` are FREE inside a blob.** SYS loads the blob address into
`zTemp0` and `jmp (zTemp0)`s to it, so the indirection has already happened before your first
instruction, and nothing on the way back reads any of the three. Verified by `GPC-BASIC/SORT.INC.BL`
through a whole shell sort.

**Not free**: `codePtr $28`, `objPtr $2A`, the number stack (X), the `NSMantissa*` / `NSStatus`
slots. Anything else in zero page belongs to the KERNAL or BASIC — do not pick an address.

> **Take these addresses from `source/application/build/rtimage.lbl`, and nowhere else.** Four
> builds in this tree lay zero page out differently — the compiler, the application, ifloat32 and
> the runtime image — and only the runtime image is what a compiled program actually runs. The
> compiler's own `zTemp0` is `$2A`, which is the runtime's `objPtr`.

> `STASH.INC.BL`'s header says a blob has no zero page at all. That is wrong, written cautiously
> before it was measured. Do not take it as the rule.

## Entry and exit

- **`CLD` first, in any blob that does arithmetic.** SYS enters with the status `PLP`'d from
  `SYS_Reg_S`, holding whatever a previous `GP.CALL` left. One stray decimal flag and every `ADC`
  address is wrong. This is not decoration.
- **X and Y are yours** — SYS saves and restores them. `A` arrives from `SYS_Reg_A`.
- The lowering is 5 bytes of p-code (`.word <addr>` + `sys`), and both handlers live below `GPBase`,
  so **a program whose only GP keyword is `GP.ASM` pays nothing for the 2 KB GP block.**

## Idioms that pay

**Long loops exit through a `JMP` reached by skipping one branch.** A relative branch reaches
±127 bytes and a real loop body is past that:

```
REM SPIN: LDA {SORT.J%}
REM CMP {SORT.GAP%}
REM BCS SPCMP
REM JMP SPPLACE          ; the exit
REM SPCMP: SEC
```

**Self-patching operand**, for a computed address — still the only route when zero page is spoken
for, but with `zTemp0/1/2` available, ordinary `(ptr),y` is usually the better transliteration:

```
REM STA LBL,X            ; X=1 patches the low byte, X=2 the high
REM LBL: LDA $FFFF,Y     ; reads through the patched operand
```

**Count-down loops leave offset 0 alone for free** — a Blitz string's length byte — but `LDY {LEN%}`
/ `DEY` / `BNE` with a zero length wraps and rewrites 255 bytes of somebody else's heap. **Guard the
length in BASIC before the `GOSUB`.**

**Copy and translate in ONE pass** (read, fold, store). String blocks never shrink, so building a
big temporary is not free and freeing it is not a thing.

## What GP.ASM is worth, and when it is not

Measured on `samples/editor`: an 80-cell row render went **2320 → 18.8** jiffies per 1000 (123×),
and the p-code got *smaller*, because the `FOR` loops removed were bigger than the ~250 bytes of
assembly. But a `GOSUB` into a blob costs **~2,570 cycles** all in, so a per-call wrapper does not
break even below roughly 170 characters of work. Measure before converting a loop —
`docs/memory/strcase-call-overhead-measured.md` has the method.

# Part 2 — 64tass, for the engine sources

Assembled by `C:\8bitProgramming\64tass-1.60\64tass.exe`. **Not ca65/cc65.**

- `.proc` / `.pend` for scoping; `_label` for locals inside a `.proc`.
- `.section <name>` / `.send <name>` — `CODE`, `DATA`, `BSS`, `BSS_NOCLEAR`.
- Data: `.byte`, `.word`, `.dword`, `.fill`, `.text`. Equates: `label = value`.
- Conditionals: `.if` / `.elsif` / `.else` / `.endif`. Macros: `name .macro … .endm`, called `#name`.
- Numbers: `$1234`, `%10101010`, `123`.
- **Anonymous labels**: `+` / `-` at line start. `+` is the next upcoming forward label, `++` the one
  after that; `-` is the most recent backward one, `--` the one before it. The forward count resets
  each time a `+` is passed.

# 65C02 reference — true for both parts

## Flags

- **Z** set when the result is 0. **N** = bit 7 of the result. **C** unsigned carry/borrow and
  shifts; `CMP` sets C when `register >= operand`. **V** signed overflow.
- **`LDA`/`LDX`/`LDY` do NOT touch Carry.** Only `ADC`, `SBC`, `CMP`/`CPX`/`CPY` and the
  shift/rotates do.

## Comparison branches

| logic | unsigned |
|---|---|
| `A == imm` | `CMP #imm` / `BEQ` |
| `A != imm` | `CMP #imm` / `BNE` |
| `A < imm` | `CMP #imm` / `BCC` |
| `A >= imm` | `CMP #imm` / `BCS` |
| `A <= imm` | `CMP #imm` / `BEQ hit` / `BCC hit` |
| `A > imm` | `CMP #imm` / `BEQ skip` / `BCS hit` |

Signed needs `SEC` / `SBC #imm` / `BVC *+4` / `EOR #$80` / `BMI`\|`BPL` — which GP.ASM cannot write
(`*+4`), so branch on a byte you have already reduced.

## Quirks

- **`BIT` immediate** (`BIT #$01`) affects **only Z** — not N or V. `BIT abs` copies bit 7 → N and
  bit 6 → V, with Z from `A AND memory`.
- **The B flag is not a real bit.** It exists only in the byte pushed by `PHP`/`BRK` (1) or a
  hardware IRQ (0).
- **`BRK` skips the byte after it** — the return address is +2, which is what makes a signature byte
  possible.
- The `JMP ($xxFF)` page-wrap bug is **fixed** on 65C02, so it does not apply on the X16.

## Cycles

Most instructions 2–4. `JSR` 6, `RTS` 6. Branches: 2 not taken, 3 taken, 4 taken across a page
boundary. Zero page is 1 cycle and 1 byte cheaper than absolute. `STZ` beats `LDA #0`/`STA`; `BRA`
beats `JMP`; `INX`/`DEX` beat `CLC`/`ADC #1` and leave Carry alone. `CMP` already sets Carry — no
`CLC` before `BCC`.

## IRQ handlers

`CLD` first (the 65C02 clears D itself, but be explicit). Keep them very short: set a flag, do the
work in the main loop.

A `.BASL` change is tested headlessly in three emulator runs — tokenise, compile, run — about 70
seconds when stopped at the right line. The full recipe, including the two stop conditions that
otherwise burn the timeout on every build, is `docs/memory/headless-basl-build-recipe.md`. **Read
the raw log, never a filtered summary**, before believing a program printed nothing.

A throwaway `.BASL` still needs its preamble, or BASLOAD silently writes nothing:

```
#SAVEAS "@:NAME.PRG"
#REM 0
#SYMFILE "@:NAME.SYM"
```

Rebuilding the compiler and the runtime image must happen **together** when a constant in
`source/common-source/source/common.inc` changes.
