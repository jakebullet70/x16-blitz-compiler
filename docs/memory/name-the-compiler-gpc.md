Call the compiler **GPC** when naming its behaviour — its number model, its runtime, its p-code.
**"Blitz" is a style name**: the 1980s Commodore 64 p-code compiler, still the word that says
"compiler" to Commodore people. It names the project (`Blitz-X16`, this repo) and the tradition, not
any shared code. **All the code here is the user's own** — never write or imply that anything was
inherited, ported or derived from C64 Blitz.

**Why:** saying "Blitz integers" attributes this compiler's design to someone else's program.

**How to apply:** GPC for the compiler and its semantics, Blitz-X16 for the project, GP.BASIC for the
keyword extension. C64 Blitz! appears only as the performance and size yardstick it is
([[blitz-c64-benchmark-yardstick]], [[blitz-x16-runtime-footprint]]).
